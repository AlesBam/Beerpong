# Beer Pong Tournament Tracker

A web application for tracking beer pong matches and player statistics. Perfect for tournaments and casual games.

## Features

- Support for 1v1, 2v2, and 3v3 matches
- Hit/miss tracking
- Player accuracy statistics
- Undo functionality for mistakes
- Modern, responsive design

## Setup

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm start
   ```

## Usage

1. Select the match type (1v1, 2v2, or 3v3)
2. Enter player names for both teams
3. Click "Start Match" to begin tracking
4. Use the "Hit" and "Miss" buttons to track shots
5. Use the "Undo" button to correct mistakes
6. Start a new match at any time using the "New Match" button
